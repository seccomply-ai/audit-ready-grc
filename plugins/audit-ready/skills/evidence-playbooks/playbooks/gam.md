# Playbook: Google Workspace (`gam`)

**Detect:** `gam info domain`. This playbook assumes GAM7 or GAMADV-XTD3, and the signed-in admin needs read access to users, roles and reports. Plain legacy GAM may lack some `print` options. When a command is unsupported, record it and turn the item into an owner request for an Admin console export or screenshot.

The CSV output of `gam print ...` contains staff names and emails. That's personal data, so it's git-ignored under `compliance/evidence/`.
