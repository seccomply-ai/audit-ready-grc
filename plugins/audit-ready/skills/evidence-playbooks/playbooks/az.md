# Playbook: Azure (`az`)

**Detect:** `az account show`. The recommended role is `Reader` plus `Security Reader`. Microsoft Graph reads also need Entra roles such as `Global Reader` or `Reports Reader`.
- Add `--output json` to every command.
- Ask which subscriptions are production and pass `--subscription <subscription>`.

**Placeholders:** `<subscription>`, `<vault>`, `<workspace>`, `<rg>`.

`az rest` is allowed only with `--method get`.
