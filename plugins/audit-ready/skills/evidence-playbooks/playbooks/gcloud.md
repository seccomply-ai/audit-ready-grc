# Playbook: Google Cloud (`gcloud`)

**Detect:** run `gcloud auth list --filter=status:ACTIVE --format="value(account)"` and `gcloud config list --format=json`.
- **Recommended roles:** `roles/iam.securityReviewer` and `roles/viewer`. Add `roles/securitycenter.findingsViewer` for SCC.
- **Output:** add `--format=json` to every command.
- **Scope:** ask which projects are production.

**Placeholders**
- `<project>`: a production project.
- `<org-id>`: the organisation id.
- `<sa>`: a service account email.
- `<location>` and `<keyring>`: from earlier outputs.
