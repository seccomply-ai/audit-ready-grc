# Playbook: GitHub (`gh`)

**Detect:** run `gh auth status`. You need at least `read:org` and `repo` scopes. For org-level security alerts you also need `security_events` or an org owner or security manager role.

**Never** add `-X`, `--method`, `-f`, `-F` or `--input` to `gh api`. Use `--paginate` for lists.

**Placeholders**
- `<org>`: the GitHub organisation.
- `<repo>`: a production repository. Ask which repos deploy to production.
- `<branch>`: the default branch.
