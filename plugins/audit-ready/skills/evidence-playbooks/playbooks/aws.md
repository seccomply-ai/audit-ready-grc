# Playbook: AWS (`aws`)

**Detect:** run `aws sts get-caller-identity` and record the account id and ARN.
- **Recommended permissions:** the `SecurityAudit` and `ViewOnlyAccess` managed policies.
- **Multiple accounts:** ask the user for the list of production accounts and the profile for each one (`--profile <p>`).
- **Regions:** get them with `aws ec2 describe-regions --query "Regions[].RegionName" --output text`. Ask the user which regions are in use, and run the regional commands only there.
- **Output format:** add `--output json` to every command.

**Placeholders**
- `<account>`: the AWS account.
- `<region>`: a region in use.
- `<bucket>`, `<trail>`, `<key-id>`, `<detector-id>`: values taken from the outputs of earlier list commands.
